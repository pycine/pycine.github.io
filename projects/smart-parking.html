01Overview

One system, three interfaces.

A smart parking system that combines camera-based vacancy detection, RFID access control, and a live touchscreen HMI, with a mobile app for registration.

An ESP32-CAM sees the lot, OpenCV identifies vacant spots, and an ESP32 coordinates entry and exit with RFID authentication and access logging. Status is surfaced on the HMI and backed by Supabase for the mobile side.

02Build

What I built

  • Built a parking system that detects vacant spaces with computer vision.
  • Added RFID authentication and access logging for entry and exit control.
  • Surfaced live parking status on a touchscreen HMI.
  • Connected a mobile registration app backed by Supabase.
  • Used an ESP32-CAM and ESP32 controller across UART and I2C peripherals.

04Highlights

Technical highlights

Edge vision

Vacancy detection runs from the ESP32-CAM feed instead of manual sensors in every bay.

Physical access control

RFID authentication and access logging make entry and exit auditable.

Local HMI

A touchscreen shows live status at the site instead of forcing users into an app.

Mobile registration

Supabase connects the physical system to a registration app without custom server maintenance.
