01Overview

Neural inference on a microcontroller.

A weather station that runs a TensorFlow-trained model directly on an STM32F407. Sensor readings are scored on-device for anomalies and predictions, with no cloud round trip.

The model is deployed through X-CUBE-AI, which turns the trained network into C code that runs inside the MCU firmware. That keeps latency low and lets the station operate on a constrained power and connectivity budget.

02Build

What I built

  • Built a weather station around an STM32F407 microcontroller.
  • Trained a neural network in TensorFlow for anomaly detection and prediction.
  • Converted and deployed the model with X-CUBE-AI as part of the firmware.
  • Ran inference directly on sensor data on the MCU, without a cloud dependency.

04Highlights

Technical highlights

MCU-class inference

The network runs inside the firmware on an STM32F407, not on a companion Linux board.

TensorFlow to C

X-CUBE-AI bridges the trained model and the constrained C runtime.

No network round trip

Inference stays local, keeping the decision path short and independent of connectivity.

Anomaly detection

The model scores sensor behaviour rather than only reporting raw readings.
