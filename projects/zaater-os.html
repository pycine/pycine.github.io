01Overview

A Linux distribution that decides at the edge.

Zaater OS is a custom Yocto distribution for an agricultural field gateway. Instead of shipping every sensor reading to a cloud service, the Raspberry Pi 3B+ runs the irrigation model locally and turns soil moisture, temperature, and weather data into a watering schedule.

The image receives telemetry over MQTT from ESP32 sensor nodes. Keeping inference on the gateway reduces the connectivity requirement and lets the system keep operating through network gaps.

02Build

What I built

  • Built a custom Yocto Linux image for a Raspberry Pi 3B+ field gateway.
  • Integrated on-device ML inference to schedule irrigation from live sensor data.
  • Fused soil moisture, temperature, and weather inputs into an irrigation decision.
  • Ingested telemetry over MQTT from distributed ESP32 sensor nodes.
  • Kept the decision loop at the edge instead of depending on a remote service.

04Highlights

Technical highlights

A custom distro

The target image is built with Yocto, not assembled from a generic Raspberry Pi OS install.

Edge inference

The model runs on the gateway, where the data is already arriving — not in a remote cloud.

Sensor fusion

Soil moisture, temperature, and weather are combined into one decision instead of three independent readings.

Gateway architecture

ESP32 nodes stay simple while the Linux gateway owns connectivity and inference.
